## ✨ Особливості збірки для M17

- 🎮 **Повне нативне керування (m17_fallout_mapper)**:
  - Лівий аналоговий стік емулює плавну мишу з комфортною кривою прискорення.
  - **L1 / L2** — Лівий клік миші (взаємодія / рух / атака).
  - **R1 / R2** — Правий клік миші (зміна курсора: дія / інвентар / огляд).
  - **Хрестовина (D-Pad)**: швидкий перехід по екрану.
  - **Кнопки дій**:
    - **A** — Інвентар (I)
    - **B** — Завершити хід у бою (Space)
    - **X** — Лист персонажа / S.P.E.C.I.A.L. (C)
    - **Y** — Pip-Boy 2000 (P)
  - **START** — Меню паузи / Налаштування (ESC).
  - **SELECT** — Карта місцевості / Автомапа (M).
  - **SELECT + START** — Швидкий вихід у меню EmulationStation.
- 🇺🇦 **Повна українська локалізація**:
  - Повний переклад усіх 973 текстових файлів, включаючи вступне відео («ВІЙНА. Війна ніколи не змінюється...»).
  - Автоматичне відображення субтитрів у всіх відеороликах (`subtitles=1`).
  - Перекладені карти міст та світу (Пустеля, Гори, Місто, Узбережжя).
  - Перекладені та виправлені діалоги Нью-Ріно, Міста Сховища, Наварро (сержант Дорнан, Люба Ніккі, Трикартковий Монте, Джон МакРі, Старий Джо).
  - Виправлено залишкове російське кодування та термінологію.
- 📺 **Оптимізований дисплей 480x272**:
  - Апаратний рендеринг через Rockchip Mali GPU / OpenGL ES 2.0 без спотворень та падіння FPS.
- 💾 **Автоматичне збирання архівів при першому старті**:
  - Ресурси гри розділені на частини до 80 МБ для відповідності лімітам GitHub. При першому запуску скрипт `Fallout_2.sh` автоматично збирає `master.dat` та `critter.dat` без участі користувача.

## 🚀 Встановлення на консоль M17

1. Завантажте [ZIP-архів репозиторію](https://github.com/MCDShema/Fallout_2_M17/archive/refs/heads/main.zip).
2. Розархівуйте вміст на вашу SD-карту у корінь (щоб папка `roms` об'єдналася з існуючою папкою `roms` на флешці).
3. Вставте SD-карту в M17 і запустіть **Fallout 2** у розділі **Ports**.
4. При першому запуску гра автоматично склеїть архіви та запустить гру. Приємної гри!
